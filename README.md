# sanoTTS — модуль синтеза речи для MajorDoMo

Озвучивает события `SAY` / `SAYTO` / `SAYREPLY` крошечными нейросетевыми голосами
[sanoTTS](https://github.com/Ampixa/sanoTTS) — 27 официальных голосов на 17 языках и 2 дополнительных русских (Ирина и Денис), 1–7 МБ на голос. Звук уходит во вкладку
браузера через WebSocket или играет из динамика сервера через модуль `terminals`.

**Без Python и без сборки.** Движок — готовая утилита `sanotts_cli` (~0,5 МБ) со встроенным
espeak-ng 1.52: статическая (musl) для Linux x86_64 / aarch64 / armv7 / x86, Android-сборка
(PIE на системном bionic, API 24+) для Termux и KSWEB, а также `sanotts_cli.exe` для Windows
64- и 32-битной (XAMPP; на ARM-Windows работает в эмуляции x64): тот же C-код, которым голоса
sanoTTS звучат в браузерной демо-версии. Движок и его исходники живут в отдельном репозитории
[sanotts-engine](https://github.com/artt652/sanotts-engine); модуль скачивает оттуда только сборку под свою платформу. Серверу не
нужны ни компилятор, ни `libespeak-ng`, ни `git`, ни bash, ни root: установщик — на PHP, скачивает
по HTTPS движок, голос и список словоформ для русского словаря, проверяя sha256 каждого файла.

Репозиторий модуля — [artt652/majordomo-sanotts](https://github.com/artt652/majordomo-sanotts), движок и голоса Ирина и Денис — [artt652/sanotts-engine](https://github.com/artt652/sanotts-engine).

Устроен по образцу [majordomo-piper_tts](https://github.com/golnet1/majordomo-piper_tts):
устройство админки, кэша и плеера и общий загрузчик `modules/prepend.php`.

## Возможности

- 🌍 27 официальных голосов sanoTTS на 17 языках и 2 дополнительных русских — Ирина и Денис, обученные по инструкции sanoTTS: русский, немецкий, французский, испанский, итальянский,
  португальский, чешский, румынский, турецкий, польский, арабский, английский, вьетнамский,
  индонезийский, хинди, непальский, китайский — все голоса sanoTTS, которые исполняет этот движок
  (кроме heart / heart-nano / trellis и chinese-xiaoya — другие архитектуры и фронтенды)
- 🧠 Локальный синтез; русский — дополнительные голоса Ирина (`irina`, по умолчанию) и Денис (`denis`), 1,84 млн параметров
  (их репозиторий — [sanotts-engine](https://github.com/artt652/sanotts-engine), `voices/`), а также `russian` (1,57 млн) и `russian-tiny` (0,51 млн) из sanoTTS
- 🎙️ Свои голоса: каталог в браузерном формате sanoTTS в `cms/sanotts/voices/<имя>/`
- 🔊 Выравнивание громкости без ffmpeg: громкость речи по BS.1770 (без пауз) → усиление до цели
  (−16 LUFS по умолчанию) → мягкий лимитер; короткие и длинные фразы звучат одинаково
- ⚡ В браузер — по предложениям: первое звучит через 0,2–0,3 с, пока синтезируются следующие;
  без этого сообщение из шести предложений ждёт ~4 с
- ⏸️ Паузы между предложениями, тишина в начале фразы
- 🎚️ Высота голоса (±8 полутонов, темп не меняется), тембр — низкие и высокие (±12 дБ), пресеты «Обычный», «Мягкий», «Яркий», «Низкий», «Высокий», «Диктор»; обработка в движке, поэтому одинаково звучит в браузере, на терминалах и в скачанном файле
- 📦 Кэш WAV с ключом по всем параметрам + автоочистка фраз, которые не звучали 10 дней (включена по умолчанию)
- ▶️ Кнопка «Проверить» — синтез и прослушивание прямо в админке
- 🔤 Для русских голосов — русские правила модуля: ударения по смыслу и соседним словам
  (замо́к / за́мок, в саду́, сто́ит / стои́т), ё (еще → ещё), числа и даты с падежами, валюты, сокращения,
  римские числа, латиница, мягкий знак и паузы на запятых; своё ударение — прямо в тексте (`зам+ок`)
  (см. [Русские правила](#русские-правила))
- ✍️ Свои правила произношения (вкладка «Произношение»): замены слов, все формы слова по `*`, регулярные выражения, ударения; «Разбор» фразы; импорт и экспорт
- 🖥️ Тип TTS `sanotts` для терминалов (звук из динамика сервера)

## Требования

| Компонент | Условие |
|---|---|
| ОС | Linux x86_64, aarch64, armv7 (Raspberry Pi 2–5) или x86; Android 7+ в Termux или KSWEB (aarch64, arm, x86_64); Windows 7+ 64- и 32-битная, в том числе ARM-Windows в эмуляции x64 (XAMPP и т. п.) |
| MajorDoMo | PHP 7.4+ с `proc_open` (или `exec`/`shell_exec`) |
| Пакеты | никаких (качает php-curl или https-потоки PHP; запасной вариант — curl/wget) |
| Права | не нужны: движок ставится от пользователя веб-сервера в `cms/sanotts` внутри MajorDoMo |
| Интернет | только при установке: raw.githubusercontent.com, запасной — cdn.jsdelivr.net (~27 МБ; для русского — ещё английский словарь, 0,2 МБ) |

## Установка

1. Загрузите `sanotts.tar.gz` через **Маркет дополнений → Установить из файла**
   или скопируйте каталоги `modules`, `templates`, `languages`, `img` в корень MajorDoMo.
2. Откройте модуль и нажмите **«Установить движок»** (секунды). Установщик на PHP
   (`modules/sanotts/bin/installer.php`):
   - скачивает готовый `sanotts_cli` под вашу систему и архитектуру из [sanotts-engine](https://github.com/artt652/sanotts-engine)
     (в `cms/sanotts/engine/<платформа>/`) и базовые данные espeak-ng;
   - скачивает список словоформ espeak-ng 1.52.0 (23 МБ) и собирает полный русский словарь,
     а также словарь ё [eyo-kernel](https://github.com/e2yo/eyo-kernel) (0,9 МБ);
   - скачивает голос — по умолчанию Ирина (3,7 МБ). Все URL и sha256 — в `native/data/sources.tsv`; если
     raw.githubusercontent.com недоступен, те же файлы берутся с зеркала jsDelivr.

   Всё ставится в `cms/sanotts` внутри MajorDoMo от пользователя веб-сервера — одинаково на Debian,
   в Docker, в Termux и в Windows: без root и sudo. В Linux и Termux установка идёт
   фоновым процессом PHP, в Windows — прямо в запросе веб-сервера (браузер следит за журналом).
   Если PHP не может проверить сертификат GitHub (в XAMPP часто не задан `curl.cainfo`), файлы
   качаются без проверки сертификата — подлинность всё равно гарантирует sha256.

   Вручную:
   ```
   sudo -u www-data php /var/www/html/modules/sanotts/bin/install.php      # Linux
   php ~/htdocs/modules/sanotts/bin/install.php                             # Termux
   C:\xampp\php\php.exe C:\xampp\htdocs\modules\sanotts\bin\install.php  # Windows
   ```
   (`--voice=german` — другой голос.)
3. Проверьте звук кнопкой **«Проверить»** на вкладке настроек.

Вручную:
```bash
cd /var/www/html/cms/sanotts
echo "Привет, мир!" | bin/sanotts_cli -d share/espeak-ng-data -v voices/irina -o t.wav
# -d данные espeak  -s темп  -p пауза между предложениями  -l тишина в начале
# -L громкость (LUFS или off)  -t текст  (-o - — в stdout)
# -O PREFIX — потоково: каждая строка входа — свой WAV (PREFIX000.wav, …), готовый файл
#             сразу объявляется в stdout строкой «N путь»; голос загружается один раз
# Windows: bin\sanotts_cli.exe -d share\espeak-ng-data -v voices\irina -o t.wav -t "Привет, мир!"
```

## Свой голос

Каталог `cms/sanotts/voices/<имя>/` с `meta.json`, `front_f16.bin` (или `front_f32.bin`) и
`dec_f16.bin` — формат `web/voices/<key>/` репозитория sanoTTS. В `meta.json` используются
`espeak_voice`, `g2p_voice_slot` (русский — `10`), `sample_rate`, `length_scale`.

**Как обучить свой голос.** Голоса sanoTTS — маленькие «ученики», дистиллированные из голоса Piper
(учителя): тембр и манера речи — его. Инструкция — [distillation-recipe.md](https://github.com/Ampixa/sanoTTS/blob/master/docs/distillation-recipe.md) в репозитории
sanoTTS: голос-учитель Piper (`.onnx` + `.onnx.json`) и тексты (несколько тысяч строк) → «пакет»
учителя (фонемы, длительности, скрытые представления, звук) → три модели-ученика (длительности,
акустическая, декодер) → совместное дообучение → голос в браузерном формате sanoTTS, каталогом в
`cms/sanotts/voices/<имя>/`. Нужны Python с PyTorch и видеокарта (подойдёт Google Colab). Так обучены
дополнительные голоса Ирина и Денис. Новый язык — [roota-language-porting-recipe.md](https://github.com/Ampixa/sanoTTS/blob/master/docs/roota-language-porting-recipe.md).

Пакеты pip-формата (`manifest.json` + `weights.fp16.bin`) этот движок не читает.

## Движок: репозиторий sanotts-engine

Готовые `sanotts_cli` и `sanotts_tashkeel` под все платформы, их исходники и скрипты сборки — в
отдельном репозитории [sanotts-engine](https://github.com/artt652/sanotts-engine); там же описано, что изменено относительно кода
sanoTTS и espeak-ng и как всё пересобрать. Модуль скачивает только сборку своей платформы:

| Платформа (каталог `bin/`) | Где |
|---|---|
| `x86_64`, `aarch64`, `armv7l`, `x86` | Linux, статически (musl) |
| `android-aarch64`, `android-armv7l`, `android-x86_64` | Termux, KSWEB |
| `windows-x86_64` | Windows 64-бит (и ARM-Windows в эмуляции x64), даже если PHP 32-битный |
| `windows-x86` | Windows 32-бит |

Ссылки и sha256 всех сборок — в `native/data/sources.tsv` (строки `engine`), закреплены на коммит
репозитория. Скачанное лежит в `cms/sanotts/engine/<платформа>/`, оттуда ставится в
`cms/sanotts/bin/`. После обновления модуля, если в `sources.tsv` новая версия движка, модуль
обновит его сам при следующем синтезе; не скачалось (нет интернета) — работает прежняя версия,
повторная попытка — через час.

**Без доступа к GitHub.** Скачайте `sanotts_cli` своей платформы (платформа написана в журнале
установки: `Installing sanotts_cli (x86_64 — …)`) и положите в `cms/sanotts/engine/<платформа>/`,
например `cms/sanotts/engine/windows-x86_64/sanotts_cli.exe`. Установщик сверит sha256 и возьмёт
файл, ничего не скачивая. Для арабского так же нужен `sanotts_tashkeel`.

## Что откуда качается

В архиве модуля — код, два списка и дополнения русского словаря: `native/data/voices.tsv` (голос →
язык → словарь espeak, описания для вкладки «Голоса»), `native/data/sources.tsv` (все загружаемые
файлы с размером и sha256, на закреплённых версиях) и `native/data/dictsource/` (см. ниже).
Установщик кладёт всё в `cms/sanotts`:

| Что | Откуда | Куда |
|---|---|---|
| движок `sanotts_cli` (+ `sanotts_tashkeel` для арабского) | [sanotts-engine](https://github.com/artt652/sanotts-engine), коммит ab492b5 | `engine/<платформа>/` → `bin/` |
| базовые данные espeak-ng (фонемные таблицы, `lang/`) | sanoTTS, `mcu/ports/wasm/espeak-data-multi` | `share/espeak-ng-data/` |
| словари языков (`de_dict`, `en_dict`, …) | там же | `share/espeak-ng-data/` |
| голоса | sanoTTS, `web/voices/` | `voices/` |
| исходники русского словаря `ru_rules`, `ru_list`, `ru_emoji`, `ru_listx` (23 МБ) | espeak-ng, тег 1.52.0 | `share/ru_dictsource/` |
| словарь ё `yo_safe.txt` | eyo-kernel, тег v4.1.3 | `share/ru_dictsource/` |
| модель огласовок `tashkeel-q16.bin` (арабский) | sanoTTS, `web/tashkeel/` | `share/tashkeel/` |

Дополнения к исходникам словаря, которые идут с модулем (`native/data/dictsource/`):
- `ru_listx.extra` — 5 982 словоформы с ударениями, которых нет в списке espeak-ng 1.52.0;
- `ru_extra` — поправки ударений и записи для омографов (`замокъъ` = замо́к), которые подставляют
  русские правила модуля (`lib/ru_frontend.php`).

Русский словарь (`ru_dict`) собирает сам движок из исходников espeak-ng и этих дополнений.

После обновления модуля, если в `sources.tsv` новые версии базовых данных или движка, модуль
докачает их сам при следующем синтезе.

## Размер архива

Архив модуля — около 0,3 МБ: движок в него не входит. «Маркет дополнений» принимает файл через
обычную загрузку PHP, а у неё по умолчанию предел `upload_max_filesize = 2M`; если файл больше,
«Маркет» молча возвращает на главную страницу.

## Android: KSWEB

Модуль работает и в KSWEB (веб-сервер для Android), проверено на Android с aarch64 и PHP 8.2.6
Установка — как обычно, кнопкой «Установить движок»; в журнале будет несколько лишних строк,
это нормально:

```
[sanoTTS] Installing sanotts_cli (android-aarch64 — Android, bionic PIE)
[sanoTTS]   /storage/emulated/0/htdocs/cms/sanotts/bin: rc=127
[sanoTTS] WARNING: из /storage/emulated/0/htdocs/cms/sanotts/bin программы не запускаются (…)
[sanoTTS]   /data/data/ru.kslabs.ksweb/files/sanotts/bin: напрямую не запускается (rc=127), запуск через /system/bin/linker64
[sanoTTS]   программы установлены в /data/data/ru.kslabs.ksweb/files/sanotts/bin
…
[sanoTTS] Done
```

Что происходит. KSWEB держит сайт на общей памяти телефона (`/storage/emulated/0/htdocs`), а с неё
Android запускать программы не разрешает. Поэтому установщик кладёт `sanotts_cli` и
`sanotts_tashkeel` во внутренний каталог KSWEB — `/data/data/ru.kslabs.ksweb/files/sanotts/bin`
(путь записан в `cms/sanotts/.bindir`, «Путь к sanotts_cli» в настройках переводится туда сам).
Приложениям под Android 10+ и оттуда нельзя запускать файлы напрямую, поэтому программы
запускаются через системный загрузчик `/system/bin/linker64` — так же работает Termux (отметка —
файл `.linker` рядом с программой). Данные espeak, голоса, словари и кэш остаются в
`cms/sanotts` и `cms/cached` на общей памяти.

KSWEB передаёт PHP переменную `LD_LIBRARY_PATH` с неразвёрнутым текстом `$LD_LIBRARY_PATH`;
модуль убирает её из окружения своих программ, иначе загрузчик на каждый запуск писал бы
предупреждение `linker: normalize_path - invalid input`.

Если установка всё же не прошла, журнал покажет причину для каждого проверенного каталога.
В Termux ничего этого не нужно: там программы запускаются из каталога Termux.

## Русские правила

Русский текст перед синтезом готовят русские правила модуля (`lib/ru_frontend.php`). Что делают:

| | Пример |
|---|---|
| Числа с падежом и родом | в 1989 году → в тысяча девятьсот восемьдесят девятом году; 2 минуты → две минуты; с 7 до 9; 5-й этаж |
| Даты, время, дроби | 29.09.2026 → двадцать девятое сентября…; 07:30; 22,5°; 2,5 часа → два с половиной часа |
| Единицы и валюты | 40%, 125 кВт, 21 кв. м, $868 млн, 1,4 тыс. грн, 5 GBP, $12.99 → двенадцать долларов девяносто девять центов |
| Сокращения и ссылки | т.е., и т.д., стр. 5, п. 1.4, § 3; ссылки с путём не читаются («ссылка») |
| Римские числа | в XVIII веке, Пётр I, при Екатерине II, глава IV |
| Латиница | Wi-Fi → вай-фай, HTTPS → эйч ти ти пи эс, config.yaml → конфиг точка ямл, Home Assistant |
| Ё | дешевый → дешёвый, еще → ещё (словарь eyo-kernel, только однозначные формы) |
| Ударение по смыслу | замо́к / за́мок (старинный замок), в саду́ / к са́ду, сто́ит / стои́т, мука́ / му́ка, го́лоса / голоса́ и др. |
| Своё ударение | за́мок, зам+ок или замОк |
| Фонемы | паузы на запятых, мягкий знак (соль, день), твёрдое л (жёлтый), приставки (суперкороткая), э в заимствованиях (тест, роутер) |

Для сводок погоды и сценариев: `км/ч`, `м/с`, `мм рт. ст.`, часовые пояса (`UTC+3` → по москве,
`MSK`, `GMT`). Время склоняется по предлогу: «с 22:07 до 1:30» → «с двадцати двух ноль семи до часа тридцати», «к 7:45» → «к семи сорока пяти». Адреса с портом: `192.168.1.5:8080`, `localhost:8123` → «… порт восемь тысяч восемьдесят»;
время рядом с латиницей («Wi-Fi в 7:30») читается как время.

Как это устроено. PHP готовит текст (числа, ё, метки ударений `замокъъ` = замо́к), спрашивает у
`sanotts_cli --g2p` фонемы клауз и отдельных слов (один запуск на сообщение) и собирает из них коды
фонем с поправками; движок синтезирует готовые коды (`sanotts_cli -I`). Ударения омографов
(`ru_extra`) входят в `ru_dict`. Исходники словаря, включая список словоформ espeak
(23 МБ), после установки хранятся в `cms/sanotts/share/ru_dictsource/`, чтобы словарь можно было
пересобрать без загрузки.

**Своё ударение.** Если модуль выбрал не то ударение, укажите его прямо в тексте фразы — в сценарии
(`say('Зам+ок на двери открыт')`), в SAY или в окне «Проверка» — одним из трёх способов:
`за́мок` (знак ударения U+0301 после гласной), `зам+ок` (плюс перед гласной) или `замОк` (одна заглавная
гласная). Отметка действует только в этом месте текста: «замок» без отметки читается как обычно.
Движок берёт произношение из словаря espeak (`ru_dict`), поэтому новую отметку модуль один раз
записывает в `cms/sanotts/share/ru_dictsource/ru_extra.user` (строка вида `замокъъ $2` — «ударение на
2-й гласный») и пересобирает словарь: первая фраза с ней готовится примерно на секунду дольше,
дальше — без задержки. Список таких ударений — на вкладке «Произношение», там же их можно удалить.
Чтобы слово всегда читалось с нужным ударением, сделайте правило (см. ниже). Работает и без mbstring.

Правила действуют везде, где звучит русский голос: SAY в браузер, SAYTO на терминалы, кнопки «Проверить» и «Скачать». Отключаются галочкой «Русские правила: ударения, ё, числа» в настройках (тогда — прежняя нормализация модуля).

## Свои правила произношения

Вкладка «Произношение»: свои правила чтения — «что → как читать». Применяются по порядку сверху вниз
до встроенных русских правил (ими можно перекрыть и встроенное чтение, например `Wi-Fi`), пока — для
русских голосов (в таблице уже есть поле языка, чтобы потом распространить их на остальные).

| Тип | Пример |
|---|---|
| Слово или фраза | `MQTT` → `эм ку ти ти`; `умный дом` → `у+мный д+ом` |
| Слово со `*` в конце — все формы | `портфел*` → `п+ортфел*` (портфель, портфеля, портфелями…); `*` в замене — окончание |
| Любой текст (и внутри слов, и знаки) | `№` → `номер ` |
| Регулярное выражение (PCRE, `$1` в замене) | `\bESP(\d+)` → `и эс пи $1` |

Ударение в замене — как в тексте (`д+ома`, `домА`, `дома́`). Без галочки «Учитывать регистр» регистр
не важен, а заглавная первая буква найденного слова переносится на замену. Правило с ошибкой (например,
неверное регулярное выражение) не сохраняется; слишком сложное выражение при выполнении пропускается.

- **▶ и «Разбор».** ▶ у правила озвучивает пример; «Разбор» (на вкладке и в окне «Проверка»)
  показывает сработавшие правила, текст после них и как фраза будет прочитана — с ударениями.
- **Кэш.** Отпечаток включённых правил входит в ключ кэша WAV: после правки фразы синтезируются заново.
- **Ударения, добавленные в словарь** — список из `ru_extra.user` (отметки ударений из текстов и правил,
  которых не было в словаре), с удалением и пересборкой словаря.
- **Хранение** — таблица `sanotts_rules` в базе MajorDoMo (создаётся при установке модуля или при первом
  обращении после обновления), попадает в штатные резервные копии; при удалении модуля удаляется.
- **Импорт и экспорт** — текстовый файл, по правилу на строку, поля через табуляцию: что, как читать, тип
  (`word`/`text`/`regex`), регистр, вкл, язык, комментарий. При импорте подойдёт и простой список
  `что = как читать` (UTF-8 или Windows-1251); режимы — добавить к имеющимся (совпадающие пропускаются)
  или заменить все.

## Высота и тембр

Модель говорит медленнее в 2^(полутоны/12) раза, и звук
пересэмплируется обратно — высота меняется, темп нет. Тембр — полочные фильтры: низкие 250 Гц,
высокие 3500 Гц (те же, что `lowshelf`/`highshelf` в Web Audio). Каждое предложение
обрабатывается отдельно, затем выравнивается громкость. В `sanotts_cli` это ключи `-P`, `-B`, `-T`.
Пресеты выставляют темп (скорость 0,95 = темп модуля 1,05), высоту и тембр:

| Пресет | Темп | Высота, пт | Низкие, дБ | Высокие, дБ |
|---|---|---|---|---|
| Обычный | 1,00 | 0 | 0 | 0 |
| Мягкий | 1,05 | −1 | +3 | −5 |
| Яркий | 0,95 | +1 | −2 | +5 |
| Низкий | 1,05 | −4 | +4 | 0 |
| Высокий | 1,00 | +4 | −3 | +2 |
| Диктор | 1,11 | −1 | +2 | +2 |

## Арабский: огласовки

Короткие гласные (харакаты) в арабском письме обычно не пишут, а голос `arabic` дистиллирован с
Piper, который перед espeak расставляет их моделью libtashkeel. Без этого шага голос получает не
те фонемы: по замеру sanoTTS совпадает лишь 44,55% id и ни одно предложение из 1977.

Огласовки расставляет отдельная утилита `sanotts_tashkeel` (движок `sanotts_cli` не меняется):
```bash
bin/sanotts_tashkeel -m share/tashkeel/tashkeel-q16.bin -t "السلام عليكم"   # → السَّلَامُ عَلَيْكُمْ
bin/sanotts_tashkeel -m share/tashkeel/tashkeel-q16.bin -o out.txt < in.txt
```
`sanotts_tashkeel` — перенос на C браузерной реализации sanoTTS (`web/tashkeel/tashkeel.mjs`, без
ONNX) с тем же порядком вычислений, исходник — в [sanotts-engine](https://github.com/artt652/sanotts-engine). Утилита и веса
`tashkeel-q16.bin` (2,4 МБ, sha256 в `sources.tsv`) качаются вместе с арабским голосом. Проверено: на 1500
предложениях корпуса Tashkeela (без огласовок, с частью огласовок, с цифрами и латиницей) результат
побайтно совпал с эталоном sanoTTS (он, по данным авторов, совпадает с Piper на 1977/1977); с
эталонными огласовками корпуса — 95,4% букв. ~0,02 с на фразу плюс запуск (~0,1 с на x86).
Модуль включает её автоматически для арабских голосов (галочка в настройках).
