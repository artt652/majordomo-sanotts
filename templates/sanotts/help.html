Описание

Общее

sanoTTS — синтез речи для MajorDoMo на движке sanoTTS: крошечные нейросетевые голоса (1–7 МБ), всё считается локально. Движок — утилита sanotts_cli (~0,5 МБ) со встроенным espeak-ng: тот же C-код, которым голоса звучат в браузерной версии sanoTTS. Без Python, фоновых служб и облака. Работает в Linux (x86_64, aarch64, armv7), на Android в Termux и KSWEB, в Windows (XAMPP).

Модуль озвучивает say(), sayTo(), sayReply() и ask(): звук уходит во вкладки браузера через WebSocket — say() — вкладкам без терминала и вкладкам терминалов с TTS sanotts, sayTo() — только вкладкам выбранного терминала; уровень важности фразы сравнивается с «минимальным уровнем сообщений» терминала (вкладкам без терминала — с общим minMsgLevel); терминал MAIN может играть из динамика сервера (галочка в настройках).

Индикаторы в заголовке
  • Голос готов / не установлен — есть ли выбранный голос.
  • WebSocket — работает ли WebSocket-сервер ядра, через который звук идёт в браузер.
  • Установлено / Установка / Не установлено / Ошибка установки — состояние движка; «журнал» открывает журнал установки.
Голоса

27 официальных голосов sanoTTS на 17 языках и 2 дополнительных русских — Ирина и Денис, обученные по инструкции sanoTTS. Ставятся на вкладке «Голоса»: скачиваются голос (1–7 МБ) и словарь espeak его языка, каждый файл сверяется по sha256.

Свой голос — каталог cms/sanotts/voices/<имя>/ в формате браузерных голосов sanoTTS: meta.json (нужны espeak_voice, g2p_voice_slot, sample_rate, length_scale), front_f16.bin или front_f32.bin, dec_f16.bin или dec_f32.bin. Словарь его языка поставит «Обновить движок».

Как обучить свой голос. Голоса sanoTTS — маленькие «ученики», дистиллированные из голоса Piper (учителя): тембр и манера речи — его. Инструкция — distillation-recipe.md в репозитории sanoTTS (на английском):

  1. Выберите голос-учитель Piper (.onnx + .onnx.json) нужного языка и подготовьте тексты: несколько тысяч строк для акустической модели, несколько сотен — для декодера.
  2. Отрисуйте учителем «пакет» — фонемы, длительности, скрытые представления и звук для каждой фразы.
  3. Обучите три модели-ученика: длительностей, акустическую и декодер; затем совместное дообучение и, по желанию, финальная «полировка».
  4. Сохраните голос в браузерном формате sanoTTS (как голоса в web/voices/): meta.json + front_f16.bin + dec_f16.bin, — и положите каталогом в cms/sanotts/voices/<имя>/. Голос появится на вкладке «Голоса».

Нужны Python с PyTorch и видеокарта (подойдёт Google Colab); обучение занимает часы. Так обучены дополнительные голоса Ирина и Денис: один рецепт и один корпус из ~12 тыс. русских фраз (Википедия и новости из Leipzig, разговорные фразы из Tatoeba, фразы для умного дома), по 1,84 млн параметров, 22 050 Гц, ≈3,7 МБ. Ирина — по Piper ru_RU-irina-medium (данные RHVoice), три круга дообучения: UTMOS 3,26 — 87% от учителя (3,73). Денис — по Piper ru_RU-denis-medium (данные NabuCasa, CC0), два круга: UTMOS 2,48 — 78% от учителя (3,19). Для языка, которого в sanoTTS ещё нет, — roota-language-porting-recipe.md.

Арабский. Короткие гласные (харакаты) в письме обычно не пишут, а голос учился на тексте с ними. Их расставляет отдельная утилита sanotts_tashkeel — модель libtashkeel (MIT), та же, что у Piper. Веса (2,4 МБ) скачиваются с арабским голосом; уже расставленные огласовки сохраняются. Отключается галочкой в настройках.

Русский текст: ударения, ё, числа

Для русских голосов текст готовят русские правила модуля (галочка «Русские правила: ударения, ё, числа», включена по умолчанию):

  • Числа и даты с падежами: «в 1989 году», «2 минуты», «29.09.2026», «07:30», «с 22:07 до 1:30» → «с двадцати двух ноль семи до часа тридцати», «22,5°», «2,5 часа» → «два с половиной часа».
  • Единицы и валюты: 40%, 125 кВт, 21 кв. м, $868 млн, 1,4 тыс. грн, 5 GBP; км/ч, м/с, мм рт. ст.; часовые пояса (UTC+3 → «по москве»).
  • Сокращения: т.е., и т.д., стр. 5, п. 1.4, § 3; римские числа — «в XVIII веке», «Пётр I».
  • Латиница: Wi-Fi → «вай-фай», HTTPS, config.yaml, Home Assistant.
  • Ё: «еще» → «ещё», «дешевый» → «дешёвый».
  • Ударение по смыслу: замо́к / за́мок, в саду́ / к са́ду, сто́ит / стои́т, мука́ / му́ка и другие омографы.
  • Произношение: паузы на запятых, мягкий знак (соль, день), твёрдое «л» (жёлтый).
Своё ударение

Если ударение выбрано не то, укажите его прямо в тексте фразы — в сценарии, в SAY или в окне «Проверка»:

  • за́мок — знак ударения после гласной;
  • зам+ок — плюс перед ударной гласной;
  • замОк — ударная гласная заглавной буквой.

Пример в сценарии: say('Зам+ок на двери открыт');. Отметка действует только там, где стоит: «замок» без отметки читается как обычно. Первая фраза с новой отметкой готовится примерно на секунду дольше — модуль записывает её в словарь движка (cms/sanotts/share/ru_dictsource/ru_extra.user) и пересобирает его; дальше та же отметка звучит без задержки. Список таких ударений — на вкладке «Произношение», там же их можно удалить. Чтобы слово всегда читалось с нужным ударением, без отметки в каждой фразе, — сделайте правило: портфел* → п+ортфел*.

Свои правила произношения

На вкладке «Произношение» — свои правила чтения: сокращения, названия устройств и комнат, бренды, слова с неверным ударением. Правило — пара «что → как читать»; правила применяются по порядку сверху вниз, до встроенных русских правил, поэтому ими можно поменять и встроенное чтение. Пока — для русских голосов.

  • Слово или фраза: совпадает целое слово — MQTT → эм ку ти ти, умный дом → у+мный д+ом. Звёздочка в конце — все формы слова: портфел* → п+ортфел* (портфель, портфеля, портфелями…); * в замене — окончание найденного слова.
  • Любой текст: и внутри слов, и знаки — № → номер . Пробелы по краям сохраняются.
  • Регулярное выражение: PCRE без ограничителей, в замене $1, $2 — \bESP(\d+) → и эс пи $1.

Ударение в замене — как в тексте: д+ома, домА или дома́. Регистр без галочки «Учитывать регистр» не важен; если найденное слово начинается с заглавной, замена тоже.

Проверка: ▶ у правила озвучивает пример, кнопка «Разбор» (на вкладке и в окне «Проверка» настроек) показывает, какие правила сработали, текст после них и как фраза будет прочитана — с ударениями. После изменения правил старые записи кэша не используются.

Ударения, добавленные в словарь — то, что модуль сам дописал в словарь из отметок ударения в текстах; ненужные можно удалить.

Импорт и экспорт: правила выгружаются текстовым файлом (по правилу на строку, поля через табуляцию) и загружаются обратно — с добавлением к имеющимся или с заменой. Подойдёт и простой список что = как читать, в том числе из Блокнота в Windows-1251. Правила хранятся в таблице sanotts_rules базы MajorDoMo и попадают в её резервные копии; при удалении модуля таблица удаляется — сделайте экспорт.

Темп, высота, тембр, паузы, громкость

Пресеты (Обычный, Мягкий, Яркий, Низкий, Высокий, Диктор) выставляют темп, высоту и тембр. Послушать — «Проверить», сохранить — «Обновить».

Темп — множитель к родному темпу голоса: 1.00 — как голос настроен, больше — медленнее, меньше — быстрее.

Высота голоса — от −8 до +8 полутонов; темп при этом не меняется: модель говорит медленнее или быстрее, и звук пересэмплируется обратно.

Тембр — низкие (полка 250 Гц) и высокие (полка 3500 Гц), ±12 дБ.

Пауза между предложениями — тишина, которой склеиваются предложения (каждое синтезируется отдельно).

Тишина в начале — защищает начало фразы: часть плееров «съедает» первые сотни миллисекунд. 0 — выключено.

Громкость. Выравнивание делает сам движок, ffmpeg не нужен: громкость меряется по речи (ITU-R BS.1770, паузы не учитываются), фраза усиливается до цели, пики держит мягкий лимитер. Поэтому «Да.» и длинное сообщение звучат одинаково. По умолчанию −16 LUFS (громко и разборчиво); −20…−23 — тише, например для ночных оповещений. Без галочки — только пик на −2 dBFS.

Высота, тембр и громкость обрабатываются в движке — одинаково в браузере, на терминалах и в скачанном файле.

Воспроизведение, проверка и кэш

По предложениям (включено по умолчанию): сообщение режется на предложения, и каждое уходит в браузер, как только готово. Первое звучит через 0,2–0,3 с, пока синтезируются следующие, и задержка не растёт с длиной сообщения. Всё сообщение синтезирует один запуск движка, плеер ставит предложения встык (Web Audio) — пауз на загрузку нет.

Терминалы: в настройках терминала включите «Может проговаривать» и выберите тип TTS sanotts.

  • Любой терминал, кроме MAIN, — это вкладки браузера: sayTo("…", 2, "имя терминала") звучит только на страницах MajorDoMo, открытых как этот терминал — по адресу с ?terminal=имя терминала (например, /menu.html?terminal=kitchen для терминала с системным именем kitchen) или с IP, указанного в поле «Хост» терминала. say() звучит и во вкладках без терминала (обычные страницы MajorDoMo). Вкладка, открытая как терминал, играет только фразы своего терминала — с его «минимальным уровнем сообщений»; если у терминала другой тип TTS или выключено «Может проговаривать», модуль её не озвучивает.
  • Терминал MAIN — сам сервер. Как он звучит, выбирает галочка «Терминал MAIN: играть динамиком сервера» в настройках (включена по умолчанию):
    • включена — из динамика компьютера, где работает MajorDoMo (Raspberry Pi с колонкой, ПК, телефон с Termux). Нужен проигрыватель: в Linux — paplay, aplay или ffplay; на Android — sanotts_play, который ставится вместе с движком (системные AAudio / OpenSL ES, громкость — канал «Ассистент», где его нет — «Медиа»); в Windows — встроенный в PowerShell плеер. Если проигрыватель не сработал, модуль пробует следующий и пишет причину в журнал; если проигрывателя на сервере нет, под галочкой в настройках появится предупреждение — установите проигрыватель или снимите галочку;
    • выключена — как любой другой терминал: во вкладках, открытых как MAIN (?terminal=MAIN или вход с IP из поля «Хост» терминала MAIN).
  • Плеер терминала — галочка «Играть плеером терминала (если настроен)», по умолчанию выключена. С ней терминал, у которого в карточке включено «может проигрывать» и выбран тип плеера (Kodi, MPD, VLC, Chromecast, MajorDroid…), получает фразу своим плеером: модуль отдаёт ему ссылку на файл через модуль app_player. Адрес сервера в ссылке задаётся полем «Адрес для ссылки плееру» (появляется под галочкой) — по нему плеер скачивает файл, поэтому он должен открываться с устройства, вместе с портом веб-сервера (например, http://192.168.1.10:8080); правка ядра не нужна. Пустое поле — адрес выбирается автоматически: IP сервера в домашней сети (сначала 192.168.*, потом 172.16–31.*, потом 10.*) и порт из BASE_URL. Адрес меняется только при сохранении настроек. Терминалы без плеера звучат как раньше — во вкладках или динамиком сервера; у MAIN с галочкой «играть динамиком сервера» звучит только динамик, даже если у него настроен плеер. Музыку, игравшую до фразы, плеер сам не возобновит.
  • Терминалы с другим типом TTS (MediaPlayer, MajorDroid и т. д.) модуль не озвучивает — sayTo() на них озвучивает их собственный TTS. Нужен голос sanoTTS — выберите у терминала тип sanotts (для плеера — с галочкой «Играть плеером терминала») или заведите для него второй терминал. Кнопка «Отправить» тоже работает только с терминалами типа sanotts.

«Проверить» и «Скачать» берут голос, темп, высоту и тембр прямо со страницы — сохранять перед прослушиванием не нужно. Длина текста не ограничена. Один файл (SAYTO, «Скачать») — до 10 минут речи; по предложениям ограничения нет.

«Отправить» проверяет путь, которым звучат фразы из сценариев: текст синтезируется в кэш, как при say()/sayTo(), и уходит либо во вкладки без терминала («Браузеры (как say)»), либо на выбранный терминал через модуль «Терминалы». Под кнопкой — что получилось на каждом шаге: где лежит файл, какую ссылку получит плеер терминала, кому передано. Голос и параметры — со страницы, как у «Проверить».

Фразы из сценариев доходят до модуля фоновым запросом MajorDoMo к самому себе по BASE_URL из config.php. Если этот адрес не отвечает (например, веб-сервер на порту 8080, а в BASE_URL порт не указан), модуль о фразе не узнаёт и файл не создаётся — над вкладками тогда будет красное предупреждение.

Кэш: каждая фраза сохраняется в cms/cached/voice/sanotts_*.wav; ключ зависит от текста, голоса и всех параметров. Галочка «Удалять редкоиспользуемые фразы» (включена по умолчанию) удаляет файлы, к которым не обращались 10 дней.

Звук уходит в браузер событием SANOTTS через WebSocket ядра; плеер sanotts.js подключается ко всем страницам сам (кроме админки) — через загрузчик cms/sanotts/prepend_loader.php, который PHP выполняет перед каждой страницей (auto_prepend_file). Он подключает плееры всех установленных модулей (как общий modules/prepend.php) и лежит в каталоге движка, поэтому не пропадёт при удалении этого или других модулей. При установке модуль прописывает его двумя способами, каждый срабатывает только там, где нужен:

  • .htaccess — блок php_value внутри <IfModule mod_php…>: Apache, в котором PHP подключён модулем (mod_php);
  • .user.ini в корне MajorDoMo — PHP в режиме FastCGI (php-fpm, php-cgi: nginx, lighttpd, Termux, KSWEB, Docker). PHP перечитывает его раз в 5 минут, поэтому сразу после установки плеер может появиться не мгновенно. Скачивание .user.ini модуль запрещает в .htaccess; в nginx и lighttpd закройте его в конфигурации сервера.

Уже настроенное модуль не трогает: если auto_prepend_file задан в php.ini или конфигурации сервера другим файлом, ни .htaccess, ни .user.ini не меняются — иначе тот файл перестал бы подключаться. Тогда в предупреждении будет строка include_once '…/cms/sanotts/prepend_loader.php'; — добавьте её в тот файл, и заработают оба. Чужие и вписанные вручную строки не удаляются и при удалении модуля.

Если плеер не подключился, над вкладками появится предупреждение с причиной. Для SPA-панелей и шаблонов, которые открываются не через MajorDoMo, добавьте перед </body>: <script src="/templates/sanotts/js/sanotts.js"></script>. Если WebSocket MajorDoMo не на порту 8001 (WEBSOCKETS_PORT в config.php), перед ним укажите порт: <script>window.SANOTTS_WS_PORT=8002</script>

Что делает кнопка «Установить движок»
  1. Скачивает готовый sanotts_cli под вашу систему из репозитория движка sanotts-engine (~0,5 МБ, espeak-ng встроен): Linux (x86_64, aarch64, armv7, x86), Android (aarch64, arm, x86_64) или Windows (64- и 32-битная).
  2. Скачивает список словоформ espeak-ng 1.52.0 (23 МБ) и собирает полный русский словарь (811 тыс. словоформ с ударениями), а также словарь ё eyo-kernel (0,9 МБ).
  3. Скачивает выбранный голос и словарь его языка, делает самопроверку. Остальные голоса — на вкладке «Голоса».

Установщик написан на PHP: не нужны ни bash, ни компилятор, ни git, ни root. Качает сам PHP (php-curl или https-потоки, запасной вариант — curl/wget), каждый файл сверяется по sha256; если GitHub недоступен, те же файлы берутся с зеркала jsDelivr. Движок ставится в cms/sanotts внутри MajorDoMo. В Linux и Termux установка идёт фоновым процессом PHP, в Windows — прямо в запросе веб-сервера; браузер следит за журналом.

Без доступа к GitHub: скачайте sanotts_cli своей платформы из sanotts-engine (каталог bin/<платформа>/, платформа написана в журнале установки) и положите в cms/sanotts/engine/<платформа>/ — установщик проверит sha256 и возьмёт файл. Голос и словарь так же качаются с GitHub.

KSWEB (Android): сайт лежит на общей памяти (/storage/emulated/0), а с неё Android программы не запускает. Установщик сам кладёт sanotts_cli во внутренний каталог KSWEB (/data/data/ru.kslabs.ksweb/files/sanotts/bin) и запускает через системный загрузчик /system/bin/linker64. Строки «rc=127» и «запуск через /system/bin/linker64» в журнале — это нормально.

Из консоли:

# Linux (от пользователя веб-сервера):
sudo -u www-data php /var/www/html/modules/sanotts/bin/install.php
# Termux:
php ~/htdocs/modules/sanotts/bin/install.php
# Windows (XAMPP):
C:\xampp\php\php.exe C:\xampp\htdocs\modules\sanotts\bin\install.php
# другой голос: --voice=german
Проверка движка вручную 
cd /var/www/html/cms/sanotts
echo "Привет, мир!" | bin/sanotts_cli -d share/espeak-ng-data -v voices/irina -o t.wav
aplay t.wav

rem Windows:
cd C:\xampp\htdocs\cms\sanotts
bin\sanotts_cli.exe -d share\espeak-ng-data -v voices\irina -o t.wav -t "Привет, мир!"

# -d данные espeak   -v голос   -o файл WAV   -t текст (иначе — из stdin)
# -s темп   -p пауза между предложениями, с   -l тишина в начале, с
# -L громкость LUFS | off   -P высота, полутоны   -B низкие, дБ   -T высокие, дБ
Не звучит
  • Нажмите «Проверить» на вкладке настроек. Если звук есть там — движок в порядке, ищите проблему в доставке: WebSocket, prepend.php, вкладка в фоне (плеер слушает только активную вкладку).
  • Журнал установки — ссылка «журнал» в заголовке (есть кнопка «Скопировать»); журнал модуля — cms/debmes/*_sanotts.txt. Вкладка «Голоса» показывает, что модуль видит на диске.
  • Если над вкладками есть жёлтое предупреждение «Плеер не подключается…» — плеер не попадает на страницы; в предупреждении указаны причина и готовая строка для php.ini. Проверить на странице: в консоли браузера (F12) window.__sanottsPlayerLoaded должно быть true.
  • Терминал молчит — нажмите «Отправить» на этот терминал: отчёт покажет, ушёл ли звук во вкладки и когда терминал последний раз открывал MajorDoMo. Вкладка терминала должна быть открыта как этот терминал (?terminal=имя); для MAIN с галочкой «играть динамиком сервера» нужен проигрыватель на сервере (см. «Воспроизведение, проверка и кэш»).
